## 使用方法

重啟 Claude Desktop 後，可以使用以下工具：

### 連接管理
- `obsidian_list_targets` - 列出可用的調試目標
- `obsidian_connect` - 連接到 Obsidian
- `obsidian_disconnect` - 斷開連接
- `obsidian_get_status` - 查看連接和監控狀態

### Console 監控
- `obsidian_start_console_monitoring` - 開始監控 console
- `obsidian_stop_console_monitoring` - 停止監控
- `obsidian_get_console_logs` - 獲取 console 日誌（支援篩選）
- `obsidian_clear_console_logs` - 清除日誌緩存

### Network 監控
- `obsidian_start_network_monitoring` - 開始監控網絡請求
- `obsidian_stop_network_monitoring` - 停止監控
- `obsidian_get_network_requests` - 獲取網絡請求（支援篩選）
- `obsidian_clear_network_requests` - 清除請求緩存

### 檔案操作
- `obsidian_list_files` - 列出 vault 中的所有檔案
- `obsidian_read_file` - 讀取檔案內容
- `obsidian_write_file` - 寫入或更新檔案
- `obsidian_search` - 在 vault 中搜尋

### 進階功能
- `obsidian_execute_js` - 在 Obsidian 環境中執行 JavaScript

## 使用範例

```
你：連接到 Obsidian 並開始監控 console

Claude：[使用 obsidian_connect 和 obsidian_start_console_monitoring]

你：顯示最近的錯誤訊息

你：讀取檔案 "Daily Notes/2024-12-04.md"

Claude：[使用 obsidian_read_file]
```

## 故障排除

### 無法連接到 Obsidian
- 確保 Obsidian 是用 `--remote-debugging-port=9222` 參數啟動
- 檢查防火牆是否阻擋了 port 9222

### 無法讀取檔案
- 確保 Local REST API 插件已安裝並啟用
- 檢查插件是否在 `http://localhost:27123` 運行

### 找不到 MCP 工具
- 重啟 Claude Desktop
- 檢查 `claude_desktop_config.json` 中的路徑是否正確

## 注意事項

- CDP 提供對 Obsidian 運行時的完全訪問 - 謹慎使用
- `obsidian_execute_js` 可以執行任意代碼 - 僅用於可信輸入
- 日誌在記憶體中保留 1 小時 - 可能包含敏感數據
- 建議在使用 Local REST API 時配置 API 金鑰以提高安全性
